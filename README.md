# Icon Studio

Windows desktop editor for monochrome icons and firmware-ready C arrays.

## Features

- Layered image import and composition
- Procedural icon generation from English prompts
- Pixel editing for preset and custom canvas sizes
- Static PNG, text, and C-array export
- Frame animation editing and C export
- Dark interface and branded application icon

Generated files are written to the `ready_icons` folder.

## Build

Run `build_installer.bat` from the project root. It creates
`IconStudio_Setup.exe`, a standard Inno Setup installer.
